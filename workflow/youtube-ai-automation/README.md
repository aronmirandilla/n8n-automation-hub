***YouTube Automation Assistant***

This n8n workflow automates the end-to-end content production lifecycle for YouTube, including trend analysis, script generation, automated voiceover integration, and multi-platform scheduling.

---

**Features**

**Trend Analysis & Ideation**: Uses Gemini 3.1 Flash lite to analyze viral topics and generate high-engagement titles and scripts.

**Multi-Modal Content Processing**: Automates the transition from text-based scripts to video asset preparation.

**Workflow Integration**: Seamlessly connects your creative tools with your YouTube channel management dashboard.

---

***Note in order to do this***

**n8n** (Must have a self-hosted or cloud).

**API Keys**: Google Cloud Console project (YouTube Data API v3), Google Gemini API, and relevant storage provider keys.

---

***Setup Instructions***

To deploy this automation, construct the workflow manually in your n8n instance by adding the following nodes and configuring them:

**Credentials**: Create and select your credentials for:

- YouTube Data API

- Google Gemini API

---

***Workflow Construction***

**Build the workflow using**: Trigger, Trend Analysis (AI), Script Generator, and YouTube API Uploader.

**YouTube API Node**: Input your Channel ID and Playlist ID.

**AI Agent**: Define your persona and content style parameters.
